# 公开部署上线清单（服务器 + 域名，免备案）

> 目标：公网开放注册、跳过 ICP 备案 → 服务器买香港/海外，域名照买。
> 本项目已 Docker 化，上线主要是「配置 + DNS」，代码无需改动。

## 一、选购

- [ ] 服务器：香港/海外节点（**不要买大陆区域**，否则绑域名做网站必须备案）
  - 腾讯云/阿里云香港轻量 2C4G，或 Hetzner CX22（2 核 4G / 40G SSD / €4.99）
- [ ] 域名：任意 .com（¥30~60/年），海外注册商（Namecheap/Cloudflare）可连实名都省
- [ ] 记下服务器公网 IP

## 二、服务器初始化

- [ ] SSH 登录，`apt update && apt upgrade -y`
- [ ] 安装 Docker：`curl -fsSL https://get.docker.com | sh`
- [ ] 防火墙只放行 22 / 80 / 443（80/443 给 Caddy）

## 三、部署项目

- [ ] 上传代码：`git clone` 或 `scp` 到服务器
- [ ] `cp .env.production .env`，填真实值：
  - [ ] `DOMAIN`、`CORS_ORIGINS`
  - [ ] `DEEPSEEK_API_KEY`、`TAVILY_API_KEY`
  - [ ] `MYSQL_ROOT_PASSWORD`、`MYSQL_PASSWORD`（两个不同的强密码）
  - [ ] `AUTH_SECRET_KEY`：`python -c "import secrets; print(secrets.token_urlsafe(48))"`
  - [ ] `AUTH_ADMIN_EMAILS`、SMTP 全项（开放注册必须能发验证码邮件）
  - [ ] `AUTH_COOKIE_SECURE=true`、`SSL_NO_VERIFY=false`
- [ ] DNS 加一条 A 记录指向服务器 IP
- [ ] `docker compose up -d --build`
- [ ] `docker compose logs -f app caddy` 看迁移和证书签发是否成功

## 四、验证

- [ ] `https://你的域名` 能打开（Caddy 自动签 HTTPS，等 1~2 分钟）
- [ ] 注册 → 收验证码邮件 → 登录 → 刷新会话
- [ ] 两个账号各自数据隔离
- [ ] 视频/笔记导入 → RAG 对话流式正常（token 实时到浏览器）
- [ ] DeepResearch 跑一轮，确认 `SEARCH_BACKEND` 和 Tavily 生效
- [ ] `docker compose ps` 三个服务都 healthy

## 五、上线前安全核对（代码已改，确认生效）

- [ ] `backend/app.py` 不再全局关闭 TLS 证书校验（改为 `SSL_NO_VERIFY` 开关，默认 false）
- [ ] `AUTH_SECRET_KEY` 已换随机值（默认值可被伪造登录）
- [ ] MySQL 使用最小权限账号 `zhiyan`，root 仅用于运维
- [ ] `DEEP_RESEARCH_MAX_COST_USD` 已设上限（并填真实单价）
- [ ] `TZ=Asia/Shanghai` 已设、app 容器 healthcheck 已加

## 六、备份

- [ ] MySQL 定期 dump：
  `docker compose exec db mysqldump -uroot -p multi_agent_platform > backup.sql`
- [ ] `app_data` 卷快照（ChromaDB / LangGraph checkpoint / skills / memory）
